# VALLON NOIR — Cinematic Noir Frontend

A portfolio-ready, static fragrance storefront with a cinematic black-and-brass art direction.

## Experience
- Editorial hero and responsive mobile navigation
- Fragrance catalogue with category filters, search and price sorting
- Product detail modal with olfactive notes
- Saved compositions / wishlist drawer
- Shopping bag with quantity controls and delivery threshold messaging
- Browser-persistent bag and wishlist using localStorage
- Editorial atelier, olfactive-world and journal sections
- Responsive layouts and reduced-motion-friendly transitions

## Frontend-only scope
The storefront is a static frontend demonstration. Product data and interactions run in the browser. No backend, database, authentication, inventory service, email provider or payment gateway is connected. Checkout displays a demo notice and does not process payments.

## Deployment
Hosted on Vercel from the `main` branch.
